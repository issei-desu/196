# 196問題シミュレーター (リクレル数チェッカー)

任意の数字を入力し、**「数字を反転させて足す」** という操作を回文数（上から読んでも下から読んでも同じ数）になるまで自動で繰り返すシミュレーターです。

## 概要
数学の有名な未解決問題である **「196問題（リクレル数 / Lychrel number）」** をブラウザ上でリアルタイムに体験できます。

- `56` $\rightarrow$ 1回（`121`）
- `57` $\rightarrow$ 2回（`363`）
- `89` $\rightarrow$ 24回（`8813200023188`）
- `196` $\rightarrow$ 何億回計算しても回文数にならない！？

## 主な機能
- **巨大桁数対応**: JavaScriptの `BigInt` を使用し、桁数が何千・何万桁になっても計算可能
- **自動実行 & 1ステップ実行**: 自動探索モードと1歩ずつ確認できるステップモード
- **速度調整**: ゆっくり〜超高速（1フレーム50回計算）まで5段階
- **履歴とメトリクス**: リアルタイムな計算式・桁数・ステップ数の表示
- **プリセット**: 有名なステップ数を持つ数字のワンクリック入力

## 使い方
[index.html](index.html) をブラウザで開くだけで動作します。
GitHub Pages を有効化するとWeb上でそのまま公開・利用できます。
