# 196 Lychrel Number Infinite Search (196リクレル数無限試行)

196がリクレル数（反転加算を繰り返しても決して回文数にならない数）でないことを証明するため、回文数が見つかるまで無限に試行（反転加算と回文チェック）を続ける高パフォーマンスC++プログラムです。

## 特徴
- **Base-10 Direct Addition**: 10進数配列のまま反転・加算・回文チェックを行うため、多倍長バイナリ変換のボトルネックが一切なく極めて高速（数万〜数十万ステップ/秒）。
- **安全なチェックポイント機能**: 定期的に現在の状態（ステップ数・桁数・現在の数値）を `checkpoint.txt` にアトミック保存。Ctrl+CやSIGTERM停止時にも即座に保存されます。
- **再開機能**: 再起動時は前回のチェックポイントから自動的に再開します。
- **バックグラウンド実行支援**: `run.sh`、`stop.sh`、`status.sh` により、ターミナルを閉じてもバックグラウンドで無限実行可能です。

## 使い方

### 1. ビルド
```bash
make
```

### 2. バックグラウンドで実行開始
```bash
./run.sh
```

### 3. 進捗状況の確認
```bash
./status.sh
```
ログをリアルタイムで監視したい場合：
```bash
tail -f lychrel.log
```

### 4. 安全な停止（チェックポイントを保存して終了）
```bash
./stop.sh
```

### 5. フォアグラウンドでの直接実行
```bash
./lychrel_196
# 最初からやり直す場合:
./lychrel_196 --reset
```

## 回文数が発見された場合
回文数が発見された場合（＝196がリクレル数ではないことが証明された場合）、直ちにコンソールおよび `palindrome_found.txt` に発見時のステップ数、桁数、数値全文が保存されます。
