# リクレル数を見つけよう！

任意の自然数を入力し、「数字を反転させて足す」という操作を回文数（左右対称な数）になるまで繰り返すシミュレーターです。

## 概要
数学の未解決問題である **「リクレル数（Lychrel Numbers）」** を検証・シミュレーションできます。
最小の候補である `196` をはじめ、任意の数で探索を行えます。

- `56` → 1回（`121`）
- `57` → 2回（`363`）
- `89` → 24回（`8813200023188`）
- `196` → 未解決（リクレル数候補）

## 主な機能
- **巨大桁数対応**: `BigInt` を採用し、桁数制限なく反転加算を実行可能
- **自動実行 & ステップ実行**: 連続自動実行と1ステップごとの確認に対応
- **速度調整**: 低速〜超高速まで5段階で調整可能
- **リアルタイム表示**: ステップ数、桁数、計算履歴を表示
